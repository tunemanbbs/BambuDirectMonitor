# Privacy Policy

Bambu Direct Monitor is a local Windows desktop application for monitoring a
Bambu Lab printer.

## Data Collection

Bambu Direct Monitor does not collect telemetry, analytics, crash reports, or
maintainer-run usage data.

## Local Configuration

The app stores its configuration locally on the user's computer in:

```text
BambuDirectMonitor-config.json
```

Depending on the selected connection mode, this file may contain local printer
settings, Bambu Cloud access tokens, printer serial numbers, LAN access codes, or
other connection details needed for the app to talk to the user's printer.

This configuration file is not sent to the project maintainer and should not be
shared publicly.

## Network Connections

When configured for Bambu Cloud mode, the app communicates with Bambu Lab cloud
services to authenticate and retrieve printer status.

When configured for LAN mode, the app communicates directly with the user's
printer on the local network.

## Third Parties

The project maintainer does not operate a server for this app and does not
receive user data from the app.

Bambu Lab cloud mode is subject to Bambu Lab's own account and service policies.
